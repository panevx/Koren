# KOREN

> Далеч от България. Близо до корените си.

Двуезично (bg/en) образователно уеб приложение за деца 4–14 г. с героите Корен и Рая.

**Демо:** https://panevx.github.io/Koren/

## Какво има сега (v0.25.0)
- **120 мисии** в 4 направления — история (27), култура (25), език (20), география (48) — всяка за 1–3 възрасти: 4–6, 7–10, 11–14 г.
  За 7–14 г. всяко ниво е игра + второ предизвикателство + 3 въпроса.
- **22 вида игри:** избор, карта, двойки, подреждане, пъзел, търсене в сцена, сортиране, мемори, сандък, „построй България“,
  „познай мястото“, води реката с пръст, области-пъзел, построй крепост, „кой съм аз?“, готвене, шевица/яйце,
  глаголически шифър, попълни изречението, регистрационни номера, „вярно или не?“, блиц (таймерът е по желание)
- **Път на приключенията** с 23 глави, отключване по прогрес, значки и медали; паспорт, Зала на славата
- **Карта** от Natural Earth и реални височини: 7 режима (забележителности, градове, области, планини, реки, съседи, туризъм);
  **линия на времето** 681–1940
- **Жълтици и сергия** — само игрова валута: калпак, мартеница, елек… върху знака на детето. Без истински пари и наказания
- **Работи без интернет**, инсталира се като приложение; до 3 детски профила; без акаунти и без лични данни
- Всички мисии са **чернови** до проверка от учител — списъкът за проверка е в [docs/REVIEW.md](docs/REVIEW.md)

Документи:
- [docs/DEMO.md](docs/DEMO.md) — сценарий за представяне (5 и 2 минути), подготовка, резервен план, въпроси на журито
- [docs/REVIEW.md](docs/REVIEW.md) — списък за проверка на фактите от учител (`npm run review-list`)
- [content/sheet/README.md](content/sheet/README.md) — как редакторът пише мисии в таблица
- [CLAUDE.md](CLAUDE.md) — правилата на проекта (технически)

## Версия 0.23 — Финални проверки (Етап 10)

- Проверки: всяко ниво на всяка мисия (490 на два езика) се отваря в браузъра без грешка; цял сценарий
  „ново дете → значка → презареждане → без интернет“; достъпност (имена, клавиатура, контраст, alt) на 116 екрана

## Разработка
```bash
npm install
npm run dev -- --host   # отвори от телефон в същата мрежа
npm test                # Vitest
npm run build           # typecheck + build
npm run build:family    # проверява одобренията за първата глава, след което компилира семейната версия
npm run review-list     # docs/REVIEW.md за учителя
```

Проверка на pull request: тестове и компилация на семейната конфигурация и демото.

Публикуване: всеки push в `main` (и в работния клон) пуска `.github/workflows/deploy.yml` → тестове → build → клон `gh-pages`.
Правилата за проекта са в [CLAUDE.md](CLAUDE.md).
