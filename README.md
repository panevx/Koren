# KOREN

> Далеч от България. Близо до корените си.

Двуезично (bg/en) образователно уеб приложение за деца 4–14 г. с героите Корен и Рая.

**Демо:** https://panevx.github.io/Koren/

## Версия 0.10 — 3D графика и животни
- Корен и Рая, лицата, иконките, нивата и пъзелите са в 3D; всяка от 12-те мисии има свой медальон
- Две нови мисии с 18 диви животни: „Животните в гората“ и „Край водата и в небето“ (14 мисии общо)
- За 4–6 г.: „Къде е мечката?“ — избор между три картинки; ново място на картата: резерват Сребърна

## Версия 0.9 — Редизайн „Playful 3D“
- Нова палитра (#138B50, #FF655C, #FFD35A, #72C8F5, фон #F8F5ED), бутони-хапчета с 3D страна, меки многослойни сенки, без рамки
- Нов хъб: Корен и Рая пред пейзаж, „Следваща мисия“, шест модула с различен размер, форма и цвят
- Плаваща навигация, преходи между екраните, пружинно натискане, реакции на героите, анимирана награда с конфети
- Motion + CSS; само transform/opacity (60 fps); спазва „намалено движение“; всичко се достига с клавиатура
- Запазени: всички маршрути и функции, BG/EN, слайдърът за възраст 4–14, запазването на настройките

## Версия 0.8 — Работа без интернет
- Инсталира се на телефона като приложение (Android: бутон; iPhone: „Сподели → Добави към началния екран“)
- Работи без интернет: цяла мисия до значката, проверено с изключена мрежа
- „Изтегли всичко за пътуване“ в секцията за родители; „Има нови мисии!“ вместо внезапно презареждане
- Lighthouse (мобилен): Performance 92 · Accessibility 100 · Best Practices 100 · SEO 100

## Версия 0.7 — Съдържание
- 12 мисии (по 3 на направление) × 3 нива = 36 различни игри; нови места на картата: Балчик, Бургас
- Импорт от таблица: редакторът пише в Google Sheets, `npm run import-content` прави JSON — с грешки по номер на ред
- Ръководство за редактора: `content/sheet/README.md`
- Всичко е безплатно до v2.0

## Версия 0.6 — Колекция и родители
- „Паспорт на пътешественика“ — спечелените значки в цвят, останалите сиви
- До 3 детски профила (прякор по избор + възраст + знак), всеки със своя колекция; „Кой играе?“
- Секция „За родители“ зад задача „7 × 8 = ?“: профили, какво учи детето, език, звук, поверителност
- Почивка след 3 поредни мисии — Корен и Рая предлагат пауза

## Версия 0.5 — Всички игри = демо
- Шаблони `match` (двойки), `order` (подреждане), `puzzle` (пъзел) — с пръст, мишка и клавиатура
- 4 мисии, по една от направление: Хан Аспарух, Баба Марта, Азбуката, Рила — всяка на 3 нива
- Звукови ефекти за верен отговор, подсказка и значка (синтезирани, изключват се от Настройки)
- Тест, който изиграва всяко ниво на всяка мисия

## Версия 0.4 — Карта
- Карта на България от Natural Earth (точни граници, Дунав, Черно море) — приближаване с два пръста, плъзгане, +/−
- 12 места; мисиите светят на картата, изиграните стават златни
- Шаблон `map` („намери на картата“) с подсказка след втори грешен опит
- „Хан Аспарух“ на 3 нива: 4–6 (картинки, без четене), 7–10, 11–14 (повече история, по-трудна карта)

## Версия 0.3 — Двигател на мисиите
- Схема на мисиите (Zod) + тест, който проверява всеки JSON файл в `content/missions`
- Екран „Мисия“ с 4 фази: история (Корен/Рая) → игра → проверка → значка; бутон „Изход“ винаги видим
- Шаблон `quiz` (текст или картинки); грешен отговор → подсказка от Рая, никога червен екран
- Първа мисия: „Хан Аспарух и новата държава“ (ниво 7–10, чернова до проверка от учител)
- Напредъкът и значките се пазят само на устройството

## Версия 0.2 — Навигация и възраст
- Хъб „Начало“ с 6 плочки и долна лента (Начало, Карта, Мисии, Колекция); неготовите раздели показват „Скоро“ и версията, в която идват
- 3 възрастови нива (`small` 4–6, `young` 7–10, `guard` 11–14) — променят размера на шрифта и бутоните, ъглите, акцентния цвят и колко текст има в хъба
- Два езика (`content/i18n/bg.json`, `en.json`) — нито един текст не е написан в кода
- Настройки (зъбно колело): език, възраст, „Запомни настройките“, „Започни отначало“
- Изборът се пази в localStorage (Zustand); при второ отваряне началните екрани се прескачат

## Разработка
```bash
npm install
npm run dev -- --host   # отвори от телефон в същата мрежа
npm test                # Vitest
npm run build           # typecheck + build
```

Публикуване: всеки push в `main` пуска `.github/workflows/deploy.yml` → тестове → build → клон `gh-pages`.
Правилата за проекта са в [CLAUDE.md](CLAUDE.md).
