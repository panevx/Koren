# Как се добавя мисия от таблица (за редактора на съдържание)

Не пипате код и JSON. Пишете в таблица (Google Sheets или Excel) — **един ред = едно нещо**:
една реплика, един въпрос, една двойка, една карта.

## Стъпки
1. Отворете `ПРИМЕР-баба-марта.csv` в Google Sheets (Файл → Импортиране). Това е истинска мисия — копирайте я и сменете текстовете.
2. Попълнете новата мисия. Колона `mission` е еднаква за всички редове на мисията, напр. `hist-04-levski`.
3. Изтеглете като CSV (Файл → Изтегляне → .csv) и го дайте на IT.
4. IT пуска `npm run import-content -- файл.csv`. Ако има грешки, скриптът казва **номера на реда** и какво не е наред; нищо не се записва, докато всичко не е вярно.
5. `npm test` изиграва мисията автоматично на всяко ниво — ако е нерешима, ще разберем веднага.

Всички мисии в таблица: `npm run export-content` → `content/sheet/missions.csv`.

## Колони
`mission | level | block | kind | bg | en | img | opt_bg | opt_en | opt_img | answer | hint_bg | hint_en`

- `bg` / `en` — текстът на двата езика. **И двата са задължителни.**
- Списъци в една клетка се разделят с ` | ` (напр. отговори `София | Плиска | Варна`).
- `level`: `small` (4–6 г.), `young` (7–10), `guard` (11–14). Празно за данните на мисията.

## Данни на мисията (`level` е празно)
| block | kind | какво се пише |
|---|---|---|
| `title` | | заглавие в `bg` и `en` |
| `meta` | `subject` | `history`, `culture`, `language` или `geography` |
| `meta` | `order` | номер за подредбата в списъка |
| `meta` | `free` | `true` |
| `meta` | `place` | място на картата (id от `content/map/places.json`), по избор |
| `meta` | `badge` | `bg` = име на значката (латиница, напр. `levski`), `img` = картинка |
| `meta` | `draft` | `true`, докато учител не одобри |
| `source` | | един източник на ред (учебник, издание, страница) — **задължително** |
| `review` | | `bg` = кой учител е одобрил, `en` = дата `2027-01-20`. Тогава `draft` = `false` |

## Нивата
| block | kind | какво се пише |
|---|---|---|
| `story` | `koren:wave` / `raya:point` / `koren:think`… | реплика (1–6 на ниво) |
| `game` | `quiz` | ред-заглавие, после редове `question` |
| `game` | `question` | въпрос в `bg`/`en`, отговори в `opt_bg`/`opt_en`, `answer` = **номер** на верния (1, 2, 3…), подсказка в `hint_*` |
| `game` | `map` или `map:icons` | задача в `bg`/`en`, места в `opt_bg`, `answer` = верното място, подсказка. `map:icons` = с картинки за 4–6 г. |
| `game` | `match` | задача + подсказка, после редове `pair`: лявото в `bg`/`en`, дясното в `opt_bg`/`opt_en` |
| `game` | `order` | задача + подсказка, после редове `item` **в верния ред** (играта ги разбърква) |
| `game` | `puzzle` | задача, `img` = квадратна картинка, `answer` = брой парчета (4, 6 или 9) |
| `check` | `question` | 0–3 въпроса за проверка (като `question` по-горе) |

## Правила
- Фактите идват от учебник, не от чат. Без източник мисията не минава.
- Грешен отговор никога не е наказание: пишете подсказка, която **помага**, а не издава отговора.
- За 4–6 г. — без четене: `map:icons`, `puzzle` или `match` с картинки.
